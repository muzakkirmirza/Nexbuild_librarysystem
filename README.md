# 📚 Campus Library System

A full-stack web application built for managing library resources, inventory, and item borrow requests efficiently. Developed as part of my internship project at **NexBuild**.

---

## 🚀 Features

- **User Authentication:** Secure login and registration system for users[cite: 3].
- **Role-Based Views:** Separate dashboards for Admins and Students to streamline operations[cite: 4, 5].
- **Borrow Request Management:** Students can request campus items (laptops, kits, etc.), and admins can approve or reject them with a single click[cite: 4, 5].
- **Loan & Transaction Tracking:** Track active loans, item issuance, return history, and maintenance logs[cite: 2, 5].
- **Modern UI:** Built with Tailwind CSS for a clean and responsive user experience[cite: 2, 3].

---

## 🛠️ Tech Stack

- **Backend:** Laravel (PHP)
- **Frontend:** Blade Templates, Tailwind CSS[cite: 2, 3]
- **Database:** SQLite / MySQL
- **Tooling:** Vite, Composer, NPM
